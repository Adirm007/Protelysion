# 0.43.1 RM2K 音效替换

127 类音效事件改用 95 段用户提供的 RM2K WAV。逐 cue 映射见 rm2k-cue-map.json。音频转换为 44.1kHz 单声道 PCM16；移动与对话循环使用短淡化片段，峰值增益与原有 cue 增益共同控制响度。BGM、战斗规则与触发节拍保持原样。

音频回归 44/44 通过；每个新文件的 WAV 格式、大小、SHA256 与完整发行清单均已核验。原有音频文件保留用于回退，当前音效清单仅引用 rm2k 资源。

音效包由作者指定的本地目录提供，未附许可文本；不将历史 CC0/CC-BY 素材的许可套用到本次音效。
