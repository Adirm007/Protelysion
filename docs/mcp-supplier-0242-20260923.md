## 4. 玩家行为与概率

1. **每次生成楼层独立判定9%，最多一名补给员。** 不再保底各刷一个事件点和休息点。
2. NPC为银灰长发、黑白裙装、黑线方牌完全遮脸的两头身像素少女。
3. 走到同格或四向相邻一格，按现有互动键/按钮进入对话。没有自动接触触发。
4. 右侧为用户图一原立绘；左下姓名框为「补给员」；底部问句严格为「要选哪个呢？」；中央仅「事件」「长椅」两个选择。图二用于布局参考，不照搬其红色战斗背景或人物。
5. 选择后关闭对话、少女消失，保留同一个物件ID、同一个坐标：事件→漂浮书，长椅→原休息长椅。**不是立刻触发事件或立刻回血；需再次互动。**
6. 书继续进入原248事件系统；长椅继续按原逻辑为在场队伍恢复40%最大HP/MP/SP，各资源受原上限约束。二者使用后仍沿用原单次消费规则。
7. 取消/返回不会消耗NPC。上下方向键选择，Enter/空格/E确认，Esc或左上关闭键返回；鼠标/触屏可直接选项。
8. 对话期间停止移动、敌方巡逻/追击和探索规则时钟。失焦暂停后可继续；按键重复、重复网络/界面输入、非法选项和过期NPC引用不会重复产出。

### 随机流和存档

`hash32(supplier-v1|runSeed|depth|visit)` 派生独立随机流，以 `roll < 0.09` 判定。它不消耗可变战斗RNG，不依赖宝箱、事件或战斗的随机次数。宝箱仍保持0.24.1最后确认的总8%（普通4%/宝箱怪4%，互斥同点）。

10万组不同seed/depth/visit的有限样本中出现9059次（9.059%），有/无NPC与三类宝箱结果的6种组合均出现。这是统计检查，不承诺每一趟严格9%或若干层后必出。

保存与恢复保留已生成楼层、NPC及选择结果，不重抽；不会静默改写玩家已存在的旧楼层。**部署新版后，新开远征或进入新生成楼层才能看到新生成规则。** 既有项目本来就在上下层时使用新的visit生成地图，本轮没有另加重刷路径。
