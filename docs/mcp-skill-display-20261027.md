# 技能与状态效果显示修复（2026-10-27）

本轮包含源码、本地构建和 0.42.1 发布包，不替换本机酒馆入口。

## 原因

- 控制状态名称表缺少石化、击倒、缴械、变形、禁动。界面又优先用控制类型覆盖状态原名，实际复现为“施加undefined”。编译后的状态名称完整。
- 领域、召唤、条件分支等只展示容器名或数量，没有展开实际执行的子效果。固定三层的描述递归也会截断较长技能链。
- 战况状态详情只接收状态定义，没有接收其 `libraryOwner` 对应的效果库，无法读取周期、触发及反击动作。

## 修改

- `09-实现/src/ui/ability-text.ts` 保留状态原名，补全控制限制；展开领域影响阵营、属性修正、周期与触发效果，以及形态、召唤物招式、命中附效、反击、到期效果、条件与检定分支、随机效果。长动作链按引用路径展开，循环处显示再次发动的名称。
- `09-实现/src/game/expedition.ts` 为战况状态说明传入所属效果库及数值上下文。
- 新增 `ability-text.test.ts` 的9项回归及 `skill-display-view.test.ts` 的实际战况视图回归。另将旧 `guard-setup-0411.test.ts` 对不存在的 `State.log` 的访问改为断言真实的 `s.notice`，恢复类型检查。
- 未修改编译器、LLM提示词、战斗规则或角色缓存；本次显示修复无需重新整备角色。
