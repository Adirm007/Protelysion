## 界面与美术

- 新 `src/ui/binding-kit.ts` 提供纸张、皮面、黄铜包角、丝带、印章、勘误条等组件，替换旧 octo-kit。正文模式面板是三根垂下的书签；下载页是环衬与锁线书帖；书间是摊开的书、藏书票名册与借书卡；手记是带索引签与口袋的旅行本；事件是章首页；设置是版权页；图鉴是博物图版；结算是版权页盖章、失败是撕页、警告是勘误条。
- 书间宽/竖两张一体图、七场加载幕的夜梦层与补给员对话立绘，用 NAI5C兔串 + nai-diffusion-5-curated 重画。夜梦采用用户指定的 13–15 岁娇小少女形象。加载幕纯背景沿用用户 10-20 选定的串 B 图；提线剧场台框与幕布沿用旧版。补给员牌面外的黑线是涂鸦溢出画板的超现实表现，不是金属圈或铁丝。对话优先读取新立绘，旧 PCK 立绘仅作加载失败后备，地图像素精灵未改。
- 物件与材质由 OpenAI 图像生成后加工；可点的精装/平装书有常态、悬停两帧。下载页之前的内联美术约 167 KB。其余 34 张 WebP 及字体、许可共 39 个文件进入 `assets/ui/` → `site/ui/`，逐项写入根清单；ResourceStore 校验后读取，缺图保留 CSS 回退。
- 展示字体是思源宋体 Heavy 与 IM Fell English 正/斜体（SIL OFL 1.1），按界面固定文字子集化、更名 Booksea Display / Booksea Latin，许可随字体。动态人物、技能、敌人名使用系统宋体。正文深墨/纸面约 13.64:1；最浅正文墨加深后约 5.43:1；名册 HP 数字至少 13px。
- 用户明确要求战斗保持旧版：`battle-stage.ts`、`battle-feedback-style.ts`、`target-arrow.ts` 与 0.46.0 一致；战斗几何和外观块沿用 0.46.0，旧套件取值仅作该块的私有常量。战斗点选仍遵守 0.23 契约。规则、存档、编译、结算和 Godot 地图没有改变。
