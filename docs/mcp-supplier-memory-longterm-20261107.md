## 1. 补给员记忆：找到的缺陷与修正

| 缺陷（长期玩下去才会暴露） | 修正 |
| --- | --- |
| 约定没有“了结”状态，她自己许的约定更是无法关闭，兑现过的约定永远挂在核心档案里 | 新增 `resolve` 操作（兑现 / 落空 / 作罢），必须有这次对话里的原话（玩家或她说的都行）；整理模型总能看到没了结的约定；了结的约定作为“已了结”往事可被想起，不减权 |
| 雷区（玩家不想被提起的事）和普通事实同等排队，记忆一多就可能挤出核心或被淘汰 | 雷区排在名字之后进核心，最多 12 条受保护、不被淘汰 |
| 模型标重要度 ≥8 即永久置顶，置顶无上限 → 存档无界、衰减失效 | 自动置顶封顶 24 条，超出时最久没被想起的降回普通记忆（重要度 7）继续衰减 |
| 重要往事（≥7）永不压缩 → 玩几百趟后往事无界 | 普通往事不够压时才压最早的重要往事，原话留进旧账 |
| 旧账合并是文字拼接后截断到 200 字 → 越旧越成半句乱码 | 旧账带结构化统计（见面、聊天、成交笔数与金额、购买、白送、全灭、撤离、最深层），合并直接相加，文字由统计重新生成；保留最多 2 句玩家原话 |
| 感想（她对玩家的整体印象）的依据往事一被压缩，感想就被删 | 依据改指向那份旧账（`d…` 编号），旧账再合并时跟着改；玩家否认某条事实时，只靠它撑着的感想才作废 |
| 等待整理的见面超过 3 次时，最早的对话被直接丢弃 | 先用确定性兜底记下名字和一句原话再出队 |
| 核心档案每句都会带上，被当成“想起”刷新近因 → 能放进核心的记忆永远不衰减 | 只有和这句话相关（过相关度门槛）的才算想起 |
| 没有日期感：不知道今天几号、生日、认识多久、多久没见 | 程序按日期算：今天日期、玩家生日（“11月7日”“11.7”“十一月七号”等）、认识满 100 天/一年、两周以上没见；开场白随之变化 |
| 关系只有一个不断上涨的熟悉度数字 | 关系里程碑（第一次聊天/成交/白送、成了熟客/老朋友/很亲近、第 10/30/50/100… 次见面、第一次平安撤离），每种只记一次 |
| 预算最紧（≈450 token）时名字、雷区、约定也可能被挤掉 | 这三类可借用检索那一半的额度，整节仍不超过总预算 |
| 向量缓存只在“忘掉”时清理，往事改写或换模型后旧向量一直堆在 IndexedDB | 每次打开清一次不再使用的向量 |
| 玩家只能“忘掉”，不能让她“一定记住” | 面板新增「记牢」（最多 20 条，不衰减、不被挤掉，改口后跟着新说法走） |

数据：`MEMORY_SCHEMA` 1 → 2。第 1 版存档读入时自动升级并写回（状态 `repaired`）；升级后的存档被旧版游戏读到时按原有设计只读、不覆盖。新增字段：`Fact.status=resolved` + `outcome`、`Fact.keep`、`Digest.stats/runFrom/runTo/quotes`、`Relationship.milestones`；感想依据可引用旧账。

## 2. 界面

- 书海记忆面板：后台整理/检索刷新时“她记得的事”不再自动收起；来源标签原先被 `li>span{flex:1}` 拉成半行宽，已修；新增「记牢」按钮、了结的约定、里程碑两栏；手机宽度下按钮换行右对齐。
- 读者命运抽卡（手机 ≤760px）：引导卡的价格行被渐隐遮罩盖住几乎看不见（缺 z-index），已修；人物立绘的白发正压在白字段落后面，改为立绘靠右上、段落占左 60%，并加主题色文字光晕。桌面布局不变。
- 没有发现缺图的位置，本轮没有调用 DrawKit/NAI。

## 3. 性能（不改玩法与美术）

书海：
- 每 50ms 发给 Godot 的帧只带 `godot/game.gd` 真正读取的字段（模式、暂停、坐标、画质与演出速度、队伍状态与颜色、楼层 id/主题/地物、首帧布局、战斗立绘 id），不再序列化技能说明、战斗日志、菜单与敌人 AI 状态；与上一帧相同就不发（每秒仍补发一次），战斗中绝大多数帧 Godot 不必再解析、重算展示指标。
- 战斗界面每 50ms 重写约 30 个相同文字节点（每次都会触发排版），改为内容变了才写（`setText/setAttr/setStyle`）。
- 每 1.5 秒把整份旅程（约 60KB 起）写进 localStorage，即使没变化，且每次都向酒馆页面广播 storage 事件；现在内容没变就跳过。

读者：
- 两处无限循环的“流光”动画改用 transform（原先动画 `left`，每帧重新排版），位移完全一致。
- 常驻信封原先每帧都在 `requestAnimationFrame` 里读位置（常驻 60Hz）；改为移动/拖动时逐帧、静止半秒后每 250ms 核对一次，窗口缩放时立即唤醒。
