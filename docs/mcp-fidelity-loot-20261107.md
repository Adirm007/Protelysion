# 编译还原、补给员战利品与文案（2026-11-07，0.45.0）

## 1. 书海编译还原

起因：命运抽卡抽到的「主神之枪」（神话·长柄武器）编进书海后只剩“物理伤害+2500、命中+0.5”与一个叫「主神之枪·主动」的技能，全伤害增幅+30%、穿透+20%、额外固定伤害+1200、每战一次必中都丢了，「相位崩解」挂到了自己身上，“无法行动（强控）”变成了只禁动作的「禁动」，精神检定也没了。

原因与修正：

- **原文结构丢失**：交给模型与本地解析的原文只有字段值，“效果名: 效果”里的效果名全丢，几条词条混成一段。现在给模型的原文保留字段名（`source-text.ts` 的 `keyedText`）；本地解析对装备的「效果」逐条处理：常驻条款合并进主体被动，带“消耗: [攻击/动作: …]”或需要发动的条款各自成为一个主动，名字用效果名（如「终焉投掷」）。
- **多条被动只留第一条**：蓝图降级时额外的被动直接丢弃。现在同一来源的多个被动合并成一个再降级，合并后降级失败才退回原做法（`blueprint/compile.ts` 的 `mergePassives`）。
- **漏认的写法**：全伤害增幅/加成+X%、穿透+X%、额外固定伤害+N（真实伤害，每次命中追加一段不随属性成长的伤害）、每场战斗 N 次的绝对命中。
- **对敌状态挂到自己身上**：“令目标进行X属性检定，失败则获得[状态]，……”现在是施加给目标的负面状态并附检定；“无法行动/强控”是眩晕类控制，只有“无法进行[动作]”才是禁动。模型蓝图里把带控制或负面的自定义状态写成自身时，除非原文写明自身陷入，程序改回敌方。“精神属性检定”“DC=30”这类写法也能读出检定。
- 真实伤害不再因句中出现“精神检定”被标成精神属性；命中、闪避、暴击、穿透的加成按百分比显示（“命中 +50%”，不再是“+0.5”）。
- 模型提示词补了一条装备规则：标签里的攻防是面板数值，每条效果都要落实，主动条款以效果名命名，并给出上面几种写法的对应蓝图。
- **旧缓存**：`COMPILE_POLICY` 升到 4。已整备过的角色点「重新整备」时，旧策略编出的装备会交给模型重编（模型失败时退回本地解析的新结果或旧结果），其它能力不动。

## 2. 补给员的可带出战利品按世界书细则写属性

之前补给员的四类交易里，遗物、道具、临时事件是迷宫内用的，效果从程序内置的白名单里挑、按品质封顶；可带出战利品只有名字、品质、类型和一句“它在正文里能做什么”，没有具体属性，进背包后只是 `效果: {说明: …}`。

现在与读者「命运抽卡」同一套做法（`src/game/supplier-loot-spec.ts`）：

1. 补给员谈成一件技能书以外的可带出战利品（武器、装备、饰品、消耗品、资产、材料），且玩家付得起时，先不成交；
2. 宿主读世界书里名称包含细则条目名的条目（角色卡 → 聊天 → 全局，启用的优先），条目名与命运抽卡共用：读者设置 `dream_gacha_settings_v1.itemSpec.entries`，没设置过时默认「技能装备道具生成规则」「品质效果限定」「核心数值表」「状态规则」；命运抽卡里关掉了细则时补给员也不写；
3. 独立生成一次（走 `booksea_supplier` 路由），让模型照细则给这件东西写 `type / tags / effects`，品质不变；
4. 成交后战利品带着这些属性，撤离结算时写进背包：`类型` 用细则写的具体类型，`标签` 追加细则标签（如“攻击: 320”），`效果` 就是细则效果，用途与来历写进 `描述`。

读不到细则、超时或模型没写出可用属性时照旧成交，只写大概，并在对话记录里说明原因。技能书不走这一步，仍由正文在研读时生成。试玩页没有世界书，不写属性。

## 3. 玩家可见文案

怪物技能说明（战斗与图鉴共用）里的开发者口吻已改写：“条款一/二/三”“仲裁”“种子随机”“公共轮”“不保证……”“品质词条投影”“唯一解/短战检查/反读取”等，改为只说明它做了什么；普通攻击说明不再提“编译失败的替代能力”；图鉴数值栏去掉“（X 级模板＋挑战成长）”。未显示给玩家的对策字段与模型提示词不改。
