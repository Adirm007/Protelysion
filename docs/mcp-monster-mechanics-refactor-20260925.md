## 2. 修改文件

- `monsters/kits.ts`：接入机制表。层级时间线：
  - 1 阶：普攻 + 两招核心技；精英 / Boss 另带被动 1。
  - 2 阶：+ 本体被动；约 65% 普通怪在此获得被动 1（其余 4 阶）。
  - 3 阶：+ 独有主动 1 + 连携；Boss 起带阶段转换（蒙红）。
  - 4 阶：+ 逆压防线 + 要素 + 被动 2。
  - 5 阶：+ 剥离护佑 + 主题权能（原有）+ **独有权能**；精英起带阶段转换（重影）。
  - 6 阶：+ 有限断源 + 法则 1 + 独有主动 2；Boss 被动 3。
  - 7 阶：+ 法则 2 + 神位 + **独有法则**；Boss + 法则 3 + 神国 + **神国原型**。
  - 七阶普通怪 ≥ 15 项、Boss ≥ 20 项（T05_B01 引力主机零式为 23 项）。
  - `kit.mechanics`（独有机制清单）与 `kit.phase` 新字段；`counterplay` 追加全部独有机制说明。
- `monsters/mechanics.ts` 中潜伏 / 隐身：五阶前只加闪避，五阶起才是真正 `hidden`（避免低层级玩家无目标可选）。
- `game/expedition.ts`：战斗视图单位新增 `phase`（读取状态 `visual:` 标签）。
- `ui/battle-stage.ts` + `ui/rpg-style.ts`：`data-phase="red"` 立绘蒙红脉动；`data-phase="afterimage"` 红蓝重影抖动。
- `tests/monster-kits.test.ts`：两条旧约束改为新政策——“T1 普通”只约束普通怪（精英 / Boss 可带一项被动）；“T2 不得有命中 / 闪避 / 速度 / 控制”只约束核心技能，独有被动是单独披露的预算。其余 70 余项怪物约束（品质、费用、法则 50% 双费、神国界碑、神位等）原样通过。
- `monsters/numbers.ts`：`MONSTER_CONTENT_VERSION` → `booksea-monsters/0.19.0`；`package.json` 0.28.0；`build-host-game.mjs` / `build-public.mjs`（含 README 模板）版本与说明。
