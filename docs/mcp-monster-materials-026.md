# 0.26.0 怪物独特素材掉落（2026-09-25）

用户审阅《怪物素材掉落表v2》后确认实装。

## 规则
- 盲盒只来自宝箱与宝箱怪；日常战斗不再掉盲盒。
- 普通/精英敌群胜利：沿用原 10% 判定，掉 1 个本场实际被击败怪物的独特素材；含 Boss 敌群沿用原 100%，固定掉 Boss 素材。
- 品质随怪物等级：Lv1–4 普通、5–8 优良、9–12 稀有、13–16 史诗、17–20 传说、21+ 神话。Boss 比同层小怪高一级，封顶神话（Boss 无普通素材）。
- 效果模板：`于{主题}·{区域}掉落的{素材名}，可用做素材`；描述为 432 条固定点评（读者／阳角少女／心爱的少女／怪人／黑幕）。
- 宝箱怪：盲盒品质等同宝箱怪等级（如 24 级为神话）；神话级宝箱怪另有 9% 掉「价值的结晶」（神话，效果：巨大结块的‘价值’本身，无论谁都会认为那是宝物，利用方式就各凭本事了）。
- 宝箱、FP、事件奖励未改；结算仍为成功撤离写入背包、失败清零。素材以 `类型:材料`、标签 `书海/怪物素材/主题/区域/来源` 写入；同名同品质同地点堆叠，不同者用限定名分开。
