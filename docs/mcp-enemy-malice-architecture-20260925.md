# 敌方恶意机制架构计划（2026-09-25，基于 LUNA/Grok 补充资料的二次审计）

状态：设计定稿，待用户确认后作为 0.29.0 / 0.30.0 实施。
资料：`Grok结果.md` §6–7、`LUNA结果.md` §6、以及本次自行检索（イニミニマニモ wiki、かえでの wiki、巴哈姆特、逗游）。
本文取代 `mcp-enemy-malice-design-20260925.md` 第 2–4 节；第 1 节（共同设计语言）仍有效，但按 §1 的勘误修正。

## 0. 结论先行

1. 0.28.0 的怪物在"手段数量"上达标，在"手段种类"上不达标：14 个恶意家族里，只有 3 个是真实存在的（限伤/回血/先手的雏形），其余 11 个要么是假的（多段=分摊总伤）、要么缺席（复活、死守狂暴、领域改规则、脚本连段、错误目标惩罚、倒计时、假分身、治疗反转、读取保命技、时间停止、羞辱线）。
2. 两部参考作的核心不是"数值大"，而是三件事：**(a) 开场改写玩家能按哪个键；(b) 每一招都在拆玩家上一步的标准解；(c) 每条恶意都有一个可查到、但不是同一个按钮的解**。0.28 的机制词表几乎全是"加成型"，没有"改规则型"，这是根本差距。
3. 因此本计划不再"往词表里加词"，而是换成**三轴设计**：`手段`（机制家族）× `窗口`（反制窗口随层级收窄）× `脚本`（固定连段替代随机技能池）。低层级弱、高层级强通过"给几条家族、留多宽窗口、是否脚本化"三个旋钮实现，而不是砍数值。
4. 现有编译器契约（`booksea-effects/2`）已经能表达全部 14 个家族：`rule:{seal_category,undying,untargetable,guaranteed_hit,no_heal,no_revive,death_guard,uninterruptible}`、`revive`、`alter_event heal_to_damage`、`copy used_latest`、`time_stop`、`damage_cap`、`counter/branch`、`summon clone`、`execute/drain/bypass`、`cast interrupt/seal`、`powerMode per_hit`。**不需要改契约，只需要新机制构建器 + 分配规则 + AI + 测试**。少数执行器行为（§9）要先验证。

## 3. 设计原则（三轴）

### 3.1 手段轴：14 个家族，每个家族三档形态

每个家族定义 **雏形 → 完全体 → 拿掉反制** 三档。层级决定最多能拿到哪一档，数量由 §5 分配表决定。

### 3.2 窗口轴：反制窗口随层级收窄，但永不为零

参考作的每条恶意都有解，但解不是同一个按钮（防御被击破拆、回避被阴沼拆、硬吃被眩晕拆）。规则：

- 每条机制在词表里必须声明 `counter`（反制标签，见 §7），UI 面板显示。
- 低层：窗口宽（蓄力 2 轮、可打断、可驱散、有预告文案）。
- 高层：窗口窄（蓄力 1 轮、只能"硬打断"或只能防御、部分不可驱散）。
- 最高层：窗口换位置（打断无效但可以驱散前置状态；必中无效但普通攻击更好打）。
- **任何层级都不允许"无解墙"**：如果一个怪同时拿到 `必中` + `回避归零` + `不可打断` + `禁技能`，必须留下 `防御有效` 或 `百分比可通` 之一。分配器强制检查（§5.4）。

### 3.3 脚本轴：随机池 → 固定连段 → 跨阶段计数

- t1–t2：随机技能池（现状）。
- t3–t4 精英/Boss：`rotation`（固定环，长度 3–5，每步可带条件分支）。
- t5+：环 + 血线插入 + 残血收池（只连打一招）。
- t7 Boss：跨阶段计数不重置（阶段切换后从环的下一步接上，玩家不能靠拖过阶段洗技能表）。

## 4. 机制家族详细设计（契约映射 + 三档 + 反制）

> 记法：`[E]` 已由契约支持、执行器已验证；`[V]` 契约支持、执行器行为需验证（§9）；数值均为初稿，实施时按 `numbers.ts` 层级曲线取值。

### F1 真多段 `[E]`
- 雏形（t1）：`hits:2, powerMode:'per_hit'`，每段 60% 威力。
- 完全体（t4）：`hits:4–6`，每段 55%，可回避（`hitRule:'normal'`）。
- 拿掉反制（t6+）：`hits:8–12` 且带 `onHitAction` 叠 DoT 或 debuff（鴉馬の嘴式 6%×18 → 我们 3%×12）。
- 反制：`evade`（高闪避逐段判定）、`guard`、`shield`（每段吃盾）。

### F2 多次行动 `[V: atb extra]`
- 雏形（t3 Boss）：半血后每公共轮 `atb extra 1`（+1 动）。
- 完全体（t5）：常驻 2 动；残血 3 动。
- 拿掉反制（t7 Boss）：3 动 + 残血 4 动，且行动次数不受减速影响（`immune_concept:'speed_down'`）。
- 反制：`control`（眩晕/冻结吃掉整轮）、`slow`（低层有效）、`burst`。

### F3 必中三档 `[E]`
- 雏形（t2）：单招 `hitRule:'guaranteed'`，威力偏低（"必中但不重"，如「叩きつぶす」≈100 固定）。
- 完全体（t4）：`ロックオン`：先手上 `evade -10` 标记（1 轮），下一动大招（两步技，可打断第一步）。
- 拿掉反制（t6+）：`guaranteed + bypass:['reduction']`（穿防御状态），或全体必中多段。
- 反制：`guard`（必中不等于穿防）、`hp`（堆血）、`break`（打断锁定→大招的第二步）。
- **规则**：我们的"必中"与 BS2 一致——只忽略闪避，不自动真伤；穿防/穿盾是另外的 `bypass` 标签，分开发放。

### F4 百分比 / 固定 / 真伤 `[E]`
- 雏形（t1）：`currentFraction 5%` 单段（食尸鬼教学：杂兵也有比例）。
- 完全体（t3–t5）：`maxFraction 20–30%` 必中单段；`currentFraction 5% ×8`；`flat` 大固定值 ×N（投げナイフ 5000×20 式）。
- 拿掉反制（t6+）：`maxFraction 50%`（肉体破壊：必中减半）；t7 Boss 一次性 `99%`（白の衝撃：开战定血不定死，`minimum` 留 1 点）。
- 反制：`reduction_percent`（新词：比例伤害减半，给玩家装备/升华用）、`shield`（比例走盾）、`heal`。
- **真伤**：只在 t7 与神国用，且 `reduction_true` 仍能减（不做"绝对不可减"）。

### F5 领域：改写玩家规则 `[V: seal_category / alter_event heal_to_damage]`
法则（law）与神国（kingdom）改为**规则型优先，数值型为辅**。领域不可驱散、不可解除、Boss 开场即放（`battle_start` 触发，t5 起；t7 Boss 阶段切换再放一条）。

| 领域 | 效果 | 反制 |
| --- | --- | --- |
| 无风 | 玩家 `seal_category:'basic'`（禁普攻）+ `evade -1` | 技能/DoT/百分比仍通 |
| 狮子奋迅 | 玩家 `seal_category:'skill'`（禁技能）+ 每轮 `armor -10%/evade -10%` 递减 | 普攻正面换血；道具增益仍有效 |
| 圣域 | 玩家每轮 `maxFraction 10%` 扣血 + `seal_category:'item'` | HP 再生可相杀 |
| 见えざる | 玩家 `guaranteed_hit` 失效（`immune_concept:'guaranteed_hit'`）+ `immune_status positive`（强化不可） | 普通高命中多段；恐惧封其回避 |
| 唄声 | 玩家 `damage ×0`（攻/魔 -100%）+ `alter_event heal_to_damage`（治疗反转，`before_heal` 触发，再生豁免） | 百分比/固定/DoT；禁回复装备 |
| 决斗裁判 | 双方 `undying`（按行动次数计时 20 动）+ 双方伤害 ×10；到期先死者负，同归玩家负 | 控制吃掉对方计数；镇魂歌有效 |
| 熔毁 | 玩家 `max_hp ×0.1` + `crit -1` | 深海盾类"最大 HP 下降无效"装备挡 debuff 部分 |
| 罪裁 | 玩家 主题属性抗性 -100% + `crit_evade -1` | 属性抗装、驱散不可 |

层级：t5 精英/Boss 1 条（限 无风/圣域/罪裁 三种轻型）；t6 Boss 1 条任选；t7 Boss 2 条（开场 1 + 阶段 1），决斗裁判仅 t7 Boss 终阶段。
现有 10 条数值法则、10 条数值神国保留为"轻型领域"给 t5–t6 普通怪使用。

### F6 蓄力 → 大招 → 打断体系 `[E: cast interrupt; V: 打断后易伤]`
- 统一结构：`charge`（状态"蓄力"，1–2 轮，可见）→ `payoff`（大招）。蓄力状态带 `onExpire → payoff`。
- 雏形（t2）：蓄力 2 轮，任何伤害可打断（`breakOnDamage`），打断后自身 `vulnerability ×1.5` 1 轮（BS2 的"击破→无防备"）。
- 完全体（t4）：蓄力 1 轮，只有带 `ai:break` 标签的技能（重击/控制）能打断；打断仍给易伤。
- 拿掉反制（t6+）：`uninterruptible`，只能防御或在蓄力完成前打死；**同一招**从可打断变不可打断（爬来的少女们：落下 → 必中落下），不换技能名。
- 半血变体（巨人的家）：t5 起半血后同招从"普通打断"变"只能硬打断"（需要 2 次打断/或控制类）。
- 大招池：全体必中×4、99% 定血、全体 30% 比例 + 裂伤、驟雨 12 连、时间停止 + 无限落下（t7）。

### F7 阶段 = 新规则 `[E]`
现有 phaseShift 改为**规则包**，按层级发放（Boss s≥3、精英 s≥5 保留触发条件）：

| 层 | 阶段内容（累加） |
| --- | --- |
| Boss t3 / 精英 t5 | 清自身负面 + 免疫控制 2 轮 + **清玩家全部增益**（`dispel positive all enemies`） |
| t4 | + 行动次数 +1（F2 雏形） |
| t5 | + 召唤 2 名庇护者（F11）或 分裂假体（`summon clone ×3`，假体死则回满复活；真身"只会反击"可辨） |
| t6 | + 全回复一次（女神之血：回满 + 清异常；玩家"虚弱"只能挡这一次回血） |
| t7 | + 第二条领域 + 残血收池（HP<30% 只连打一招） + 跨阶段计数不重置 |

去掉 `伤害×1.25 速度×1.15` 这种纯数值阶段（保留视觉：红色蒙层/重影）。

### F8 复活 / 死守 / 羞辱线 `[E: revive/undying/death_guard]`
- 雏形（t3 精英/Boss）：`death_guard ×1` → 回 30%（不再是"扛一次"，而是站起来）。
- 完全体（t5）：`before_down → revive 50%`，复活时 `dispel` 自身异常 + 强化一阶；t6 复活 2 次，每次强化。
- 死守狂暴（t5 精英/Boss）：`death_guard onTrigger → 状态"死守"`（2 公共轮 `undying` + 伤害 ×2 + 每轮 `atb extra`），到期 `onExpire → resource hp set 0`。UI 显示"2 轮后倒下"。
- 羞辱线（t7 Boss 最后一次复活）：复活后第一动 `獣の衝撃`：全体 `resource hp set 1`（不致死，`minimum 1`），随后正常行动。
- 反制：`no_revive`（玩家封复活类技能/装备）、`burst`（在触发前一次性打空——BS2 明示"阶段技可以被秒过"）、`timer`（死守是可见倒计时）。
- 延迟宣告（暴殺天使，t7 Boss 限）：开场 `天使の宣告` 3 轮后 `execute`（穿 death_guard/revive：`bypass:['death_guard']`），只有"镇魂歌"类（玩家 `undying` buff）能挡。

### F9 回血 / 回满 `[E]`
- t1–t2：无常驻回血（保留 15% 一次性）。
- t3：每轮 5%；t5：10%；t6 Boss：20%（冬骑士）。
- t7 Boss 特例："每轮回满"（暴殺天使式）——只在 HP ≥ 50% 时生效，半血后变成 F8 复活；含义是"上半管只有爆发算数，下半管开始真正的战斗"。
- 反制：`no_heal`（虚弱/出血/毒压回复）、DoT（"毒和出血比硬拼有效"）。

### F10 限伤 / 免伤 `[E: damage_cap]`
- t3 Boss：`damage_cap 50%/轮`；t5：35%；t7：25%（普通怪 t5+ 35%、t7 25%）。
- 附加：`比例伤害减半`（溶解王，t6+）、`会心无效`（t5+ Boss 固定）、`免疫元素`（1 种，t4+）。
- 反制：多段小额（限伤按轮不按段）、DoT、拖长回合（但被 F12 惩罚——这是"两难"，是故意的）。

### F11 杂兵关系 `[E: summon + triggers]`
- 会复活的杂兵（t4）：召唤物死后 N 轮 `revive`（N=4→3→2 随层级），Boss 死则一起消失（`removeOnDeath` 链接到主人）。
- 庇护者（t5）：`substitute` 规则，杂兵替主人吃单体伤害；击杀庇护者反而让主人 `atb extra`（ベラー式逆向增援，t6）。
- 不该打的同伴（t5）：`監視者の瞳`：被攻击时对攻击者 `maxFraction 100%` 自爆（`damage_received → damage`），打死会再出。正确行为是忽略；UI 标"勿击"。
- 击杀增殖（t4）：杀 1 出 2（`after_down → summon ×2`），上限 6。
- 击杀顺序（t7 Boss）：杀 A 则 B 逃跑，杀 B 则 A 自爆并全体回满（食人鬼）。
- **测试约束**：所有召唤/假体必须 `untargetable` 有时限或留至少一个合法目标，避免远征集成测试的自动选目标死循环（0.28 教训）。

### F12 倒计时 / 短战检查 `[E: counter + branch]`
- 雏形（t3）：7 轮炸弹（粘着爆弾：到期 `maxFraction 60%`，防御可减）。
- 完全体（t5）：10 轮即死（原型：前 10 轮只"微笑"（空过 60%），到期 `execute` 全体）；崩溃阶段重置计数再来一次。
- 拿掉反制（t7）：第 3 轮起"打中即死"（坠落魔：`counter ≥3` 时其所有命中 `execute`），或 25 轮强制败北（漂白世界）。
- 反制：`burst`（明示"必须速攻"）、`undying`/镇魂歌、`break`（打断计数动作）。
- **可见性**：所有倒计时以状态图标 + 数字显示；计数口径统一为"3→2→结束"（BS2 单源，但对玩家更狠且更清楚）。

### F13 脚本连段 `[需要 kits/AI 扩展，契约不变]`
- kit 新字段 `rotation:{steps:[{action,when?}],restartAt?,phaseCarry:boolean}`。
- 步骤类型：空过/自疗/上 buff/击破/必中/比例多段/蓄力/大招。
- 三条模板（对应资料里的三种环）：
  - **护士环**（5 步）：自疗 → 多段+DoT → 睡眠+50% 比例 → 全能力↑+不可解除蓄力 → 12 连。
  - **女王环**（6 步，每步拆上一步的解）：空过 → 击破（拆防御）→ 必中×4 → 必中 3% 比例+解除回避+全能力↓ → 6%×18 可回避 → 回避↑+下轮冲锋（可打断）。
  - **狮子环**（4 步，半血后收池只剩第 4 步）：裂伤 → 必中+防↓ → 弃防+雷附 → 3 连吸血。
- t5+ 环内插入血线事件（50%），t7 跨阶段计数不重置。
- AI：`combat-ai.decide()` 先查 rotation，有则按步执行（条件不满足则跳步），无则回落到效用打分。

### F14 读取与反读取 `[V: copy used_latest / 条件触发]`
- 读取保命技（t6 Boss）：玩家侧出现 `undying`/复活类 buff 时，Boss 下一动必定 `dispel includeUndispellable` 该类（反魂歌）。反读取：这会强制它空过一动，玩家可以用它锁招——保留这个洞，这是"反制的反制"。
- 抗性类别穿透（t5）：一种控制不在"全异常免疫"里（新控制键 `paralyze`，仅 `immune_status:'paralyze'` 能挡，且它拆防御/回避）。
- 模仿（t7 Boss）：`copy used_latest` 玩家上一招（■■■■ 用玩家的脉动/肉体破壊）。
- 随机牌/骰子（t6+）：`variable random_int` 1–6，6 则 `repeat ×6`；抽牌 1/4 为 100% 比例（小丑）。威胁来自方差。

## 6. 数据结构变更（不改契约）

- `mechanics.ts`：新增 `family: 'F1'…'F14'`、`form: 'seed'|'full'|'unbound'`、`counter: CounterTag[]`、`seals: CounterTag[]`（它封掉玩家哪些解）字段；构建器按 `c.stage` 选档。

## 7. 反制标签词表（`CounterTag`）

`evade`（高闪避）· `guard`（防御指令/减伤）· `shield`（护盾吃段）· `break`（打断蓄力）· `hard_break`（需重击/控制打断）· `dispel`（驱散前置状态）· `no_heal`（压回复）· `percent`（比例伤害打厚血）· `guaranteed`（必中打高闪避）· `burst`（在血线/倒计时前打空）· `ignore_adds`（忽略杂兵打本体）· `kill_order`（特定击杀顺序）· `timer`（可见倒计时，撑过/抢先）· `undying`（镇魂歌类挡延迟即死）· `fear`（恐惧封其回避）· `control`（眩晕吃掉多动）· `dot`（持续伤害绕过攻/魔归零）。

每条机制 `counter` 至少 1 项；`unbound` 档允许把 `seed` 档的 counter 换成另一项，但不能为空。

## 9. 实施前必须验证的执行器行为

1. `atb extra` 在公共轮触发下是否真正追加一次完整行动（含技能选择）。
2. `rule seal_category` 的 category 键与玩家技能分类（basic/skill/item）是否对齐。
3. `alter_event heal_to_damage` 能否由状态 `before_heal` 触发且豁免 tick 再生。
4. `undying` 到期后 `onExpire → resource hp set 0` 是否触发正常倒下流程（不再触发 death_guard）。
5. `summon clone` 的假体是否可独立 `revive`；真身/假体标签能否被 UI 读取。
6. `untargetable` 到期与远征集成测试的自动选目标兼容（0.28 教训：不能出现零合法目标）。
7. `damage_cap` 是否按公共轮重置（`reset:'round'`）。
8. `copy used_latest` 对玩家 ST 酒馆生成技能的可复制性（技能可能带自定义 library）。

## 10. 明确不采用

- 真实时间压力（福音每 3 分钟）：我们的战斗时钟以公共轮为主，改用"轮计数"代替。
- 成人向剧情内容；未交叉验证的数值（80000 固定、20 动、80% 复活率）不作为实现依据。
- "随机猜真身"作为分裂假体的唯一解——必须有可观察差异。
- 把"恶意"当成每只怪的默认皮肤：t1 普通怪保留 20% 的"负向样本"（空过/回复药/单一花招）。
