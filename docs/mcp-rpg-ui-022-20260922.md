日期：2026-09-22。目标仓库：Adirm007/Protelysion。

## 范围与操作约束

本轮仅处理《书海》开发工作区及其独立发行目录，未接触其他项目；未使用真实模型、替玩家操作远征、清空存档或更改角色数值。

MCP 已完成初始化和工具枚举。按 Bridge 规则先建立完整任务清单，读取后用带版本哈希的补丁修改；并行只用于无依赖的读取与检查，修改后运行诊断、类型检查、测试和 Godot 实际构建。阶段状态通过 set_todos/report_progress 回报。发行使用既有独立 Git 检出与 Git Credential Manager，不读取或输出凭据，不强制推送。

## 五项问题与实现

### 1. 探索书页

运行包的 `sharedMap` 只有尺寸、悬浮与世界高度信息，没有旧代码直接解引用的 `foot`、`opaqueBounds`。`16-Godot可玩区域/godot/monster_art.gd` 现在从实际透明纹理的有效区域计算锚点与像素比例，对存在的旧锚点保持兼容。共用原有 64×80 书页，实际有效高度保持 0.72 世界单位，不新生成或替换怪物美术。

### 2. 战利品描述

`09-实现/src/core/settlement.ts` 将盒内效果写为“打开后获得轨道失落主题随机稀有消耗品*1。”这样的结果描述。堆叠数量和每盒一个产物分开，原未开启标签与延后开启规则不变。只改变新结算物品的文案，不擅自遍历并重写玩家已有背包。

### 3. 真正的全屏与游戏内菜单

全屏对象改为游戏舞台，不再是带装饰边框、导航和页脚的大厅。画布跟随实际舞台尺寸；原生全屏不支持时退为当前窗口内铺满，不声称可越过浏览器权限。退出全屏和关闭游戏会清理监听并恢复滚动。

用户补充明确：上下铺满后，少量左右黑边可以接受，不以去除左右黑边为验收目标。

空地交互键 E 打开暂停菜单；有交互点时仍优先交互。队伍、行囊、遗物、战况、画质、动画、声音和返回入口集中在菜单内。菜单中的战外技能在同一规则入口执行一次，随后继续保持暂停。触屏方向键、交互键保留。

### 4. 前视 RPG 战斗

规则继续由 TypeScript 唯一执行，Godot 保留真实地图和已打包立绘。新共享表现层位于 `09-实现/src/ui/battle-stage.ts`、`09-实现/src/ui/expedition-ui.ts`、`09-实现/src/ui/rpg-style.ts`，覆盖宿主与独立入口：

- 实际遭遇地图持续可见，并以模糊、压暗处理为战斗背景。
- 敌人立绘居中，不套数据卡；我方头像、HP/MP/SP、行动条在底部。
- 右侧指令按特技、物品、防御、逃跑组织；法术、遗物、收藏和基础动作按实际能力提供子分类，长列表在窗口内滚动。
- 按用户补充截图重做技能页：顶部横贯画面的技能介绍，底部横贯画面的双列列表，替换原来的右侧悬浮小窗。浏览时收起底部队伍/指令栏，不再叠加多个窗口；确认后回到合法目标选择。
- 鼠标悬停、方向键和触屏点选均更新高亮与上方介绍；单次点选仅预览，不扣费。确认按钮或键盘 Enter 才选择技能。不可用技能仍能浏览原因，但不能确认。Home/End 和双列上下左右导航可滚到长列表末尾。
- 目标选择使用实际合法目标，可点敌人、队友和目标名，支持多选与确认。
- 敌我动作均由真实已结算结果产生战报、伤害、恢复与倒地表现；演出期间收起行动菜单，短暂阻止规则继续推进，不重算伤害、不二次扣费。
- 最后一击在战斗清理前捕获，播放结束后才切换显示，不改动结算的原子性。演出时钟不写入存档。
- 原立绘由 Godot 从 PCK 按需导出到当前页面内存，每张只传一次；没有新外链或额外素材库。

宿主头像依据只读参考 `05-外链源码快照-只读/状态栏1.9.20.html`：读取 `status-avatar-db/avatars` 中当前角色作用域的精确键 `status:<角色名>::player::主角` 或 `status:<角色名>::partner::<伙伴名>`。尊重删除标记，支持上传图、保存的 URL、主角默认头像与聊天变量伙伴 URL。读取失败仅回退姓名占位，不阻止游戏；不扫描其他角色头像，不写头像库，不把头像写入远征存档或上传仓库。

### 5. 玩家文案

移除旧界面的引擎、程序化地图、后台时钟、编译/宿主同步结构说明和重复底部详情面板。保留简短操作提示、真实费用、状态、保存失败与可重试反馈。许可仍在制作名单，不在游戏画面长篇展示。
