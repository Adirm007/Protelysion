# 补给员长期记忆 · 玩家说明

补给员会记住你：你的名字、你希望她怎么称呼你、你们的约定和玩笑，还有你们在哪层见过、买过什么、哪一趟全灭败退。**什么都不配也能用**。下面的接口都是可选的，配上以后她更能听懂你换了说法的问题。

## 记忆存在哪里

- 记忆跟着**当前聊天（也就是这个存档）**走，存在聊天变量 `booksea.supplierMemory` 里，换一个聊天就是另一位补给员。
- 记忆**不写进楼层快照**：删楼层、回退、读旧存档点都只回退旅程进度，补给员的记忆不会跟着回退。
- 你填的 API 密钥只存在这台设备的浏览器里（`localStorage`），**不会**写进聊天存档，分享存档也不会泄露。

## 杀害与清空

- 在补给员面前选「杀害」，她的记忆会**立刻全部清空**，下一位就是「第 2 任补给员」。新一任不认识你，开场白会变成「新面孔」；被问起前任，她只知道前任被你杀了。
- 在记忆面板里点「清空记忆 → 确认清空（不可恢复）」也会换一任补给员，区别在于新一任只知道「前任的记忆被清空了」。
- 清空**没有后悔药**：读回杀害之前的存档、回退楼层，甚至把聊天文件换回旧副本，都找不回旧记忆（这台设备会记下“她已经被清空过”）。
- 某一条记错了，可以在面板里对那一条点「忘掉」，不必整份清空。
- 想让她一定记住的，点那一条的「记牢」：记牢的事不会随时间淡忘，也不会因为记忆太多被挤掉（最多 20 条）；你改口时（比如换了最喜欢的食物），「记牢」会跟着新说法走。
- 关闭「长期记忆」开关后，她不再记新的事，也不会提起旧的事。但「杀害」照样会清空记忆。

## 可选：让她更懂你（记忆面板里设置）

| 设置 | 作用 | 推荐填法 |
|------|------|----------|
| 向量检索（Embedding） | 能听懂换了说法的问题，比如“我的猫” ↔ “宠物” | 点「一键填写：硅基流动」→ 地址 `https://api.siliconflow.cn/v1`，模型 `BAAI/bge-m3`，再填你的密钥 |
| 重排（Rerank） | 先粗筛二十条候选，再让重排模型挑出真正相关的 | 硅基流动 `BAAI/bge-reranker-v2-m3`；也支持 Jina / Cohere 的同款接口 |
| 记忆整理模型 | 每次见面结束后，把“关于你的事”整理进记忆 | 默认跟随补给员对话的接口；也可以填一个便宜的独立模型；选「不用模型」时只记事件、价格和你的原话 |

- 每项都有「测试连接」按钮，填完先测一下。
- 接口连不上或超时，会自动退回纯关键词检索，聊天照常进行。
- 「注入预算」控制每句话最多带多少记忆：紧凑约 450 token，标准约 800，宽裕约 1400。

## 她怎么记、怎么回忆（简述）

- **记事件**：见面、购买、成交、远征结局、杀害由游戏规则直接记账，不经过模型，所以价格和物品不会记错。
- **记你说的话**：整理模型只能记你**逐字说过**的话，编出来的“原话”会被拒收。你改口时（比如最喜欢的食物从草莓换成牛油果），旧说法会被标成「已过时」并保留历史，不会被当成现在的说法。
- **回忆**：核心档案（称呼、约定、印象、最近一次见面）几乎每轮都带上；往事按你这句话检索，综合考虑相关度、远近和重要度。宁可少提，也不硬塞无关的回忆。

## 长期陪伴（第 2 版记忆）

- **约定会了结**：你答应她的、她答应你的，兑现、落空或作罢以后会标成「已了结」，不再一直挂在嘴边；你问起当初的约定，她记得是怎么了结的。了结也要有对话里的原话为证，模型不能自己判定。
- **雷区**：你明确说过不喜欢、不想被提起的事，每次都会优先放进她的记忆，不会因为记忆太多被挤掉。
- **日子**：她知道今天是几月几日；你告诉过她生日，那天她会知道；认识满 100 天、满一年，或者好久没见（两周以上），她也知道。开场白会跟着变。
- **里程碑**：第一次聊天、第一次成交、成了熟客、第 10 次见面、你第一次平安撤离……程序按规则记下，在记忆面板里能看到。
- **玩得再久也不会撑爆存档**：很旧的见面会压成“旧账”，见面次数和成交金额按统计累加，一分不差；你那时说过的话会留一两句在旧账里；她对你的整体印象不会因为旧事被压缩而消失。
- **整理模型连不上时**：排队等整理的见面超过 3 次，最早的那几次会先用程序兜底记下你的名字和一句原话，不会整段丢掉。
- 旧版记忆存档第一次打开时会自动升级；升级后的存档用旧版游戏打开时只读、不会被覆盖。
